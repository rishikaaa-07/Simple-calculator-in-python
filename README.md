# 🧮 Simple Python Calculator

A beginner-friendly calculator built in Python that performs basic arithmetic operations:
- Addition
- Subtraction
- Multiplication
- Division
- Average calculation

This project is perfect for learning Python fundamentals and showcasing simple command-line applications.

---

## 🚀 Features
- Clean and easy-to-understand code
- Handles multiple operations
- Interactive user input
- Beginner-friendly structure
